# 🍔 Burger Craft — Hamburgueria Artesanal & Smoked House

Uma aplicação web moderna, dinâmica e 100% responsiva para a hamburgueria artesanal **Burger Craft**. O projeto foi desenvolvido com foco em alta conversão, apetite visual (*food appeal*), navegação intuitiva, cardápio interativo com filtros por categoria, formulário de pedidos para delivery/retirada e sistema de reservas de mesas.
